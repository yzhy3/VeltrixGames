VELTRIX GAMES — Roles: Creador > Admin > Usuario

ROLES
  CREADOR  Solo él puede dar/quitar admin y agregar más admins.
           También tiene el panel admin (subir juegos, etc.).
  ADMIN    Puede usar el panel admin (/admin/) para subir/editar juegos.
  USUARIO  Login, perfil, reseñas, chat.

CÓMO SER CREADOR (una sola vez)
  1. Entra a la web y crea tu cuenta (login normal).
  2. En Firebase Console > Authentication > copia tu UID.
  3. Firestore > crea colección "creators" > documento con ID = tu UID
     (puedes poner un campo ok = true).
  4. Recarga /admin/ → verás badge CREADOR y la sección "Gestionar Admins".

CÓMO DAR ADMIN (solo el creador)
  1. Entra a /admin/ con tu cuenta de creador.
  2. Sección "Gestionar Admins" → pega el UID del usuario → Agregar admin.
  3. Para quitar: botón Quitar junto al UID.

CHAT
  - Mantén presionado tu mensaje → Editar / Eliminar
  - Clic derecho en PC también
  - Los editados muestran (editado)

REGLAS
  Sube firestore.rules a Firebase > Firestore > Reglas > Publicar.
